# Klir Prospect (Perchance MVP)

Plateforme Prospect Intelligence + AI Sales Automation — flux critique : SEARCH → QUALIFY → SELECT → CRM → AI OUTREACH.

## Fichiers
- `main.pjs` : imports `ai-text-plugin` (Klir AI / messages), `kv-plugin` (réservé).
- `index.html` : shell + CSS.
- `src/data.js` : secteurs, villes, noms procéduraux.
- `src/engine.js` : parseQuery, genProspects, dedup (fingerprint), scores Q/R, analyse IA.
- `src/store.js` : persistance localStorage `klir_prospect_v1` (legacy) + `klir_prospect_v2_<email>` par compte + `klir_accounts_v1` (email→hash) + sauvegarde kv-plugin en arrière-plan. Recherches/CRM liés à l'e-mail.
- `src/webintel.js` : WEBSITE & DOMAIN INTELLIGENCE (statuts site/domaine séparés, DNS via dns.google, HTTP via superFetch, RDAP .com/.ca, cache 24h, bulk ≤100/batch). Échec → ⚪ UNKNOWN, jamais « disponible » sans preuve RDAP/registre.
- `src/opportunity.js` : OPPORTUNITY INTELLIGENCE ENGINE v1 (ICP 0-100, signaux typés avec preuve/source/confiance/poids + plafonds par groupe, 6 besoins, matching 6 services Klirline, score 30/25/25/20, priorités, gates DQ<40 et confiance, versioning). Configurable dans Admin.
- `src/app.js` : SPA hash-router (landing, login/register/forgot, onboarding, dashboard, prospecting/new/searches/results, prospects, crm, campaigns, ai, analytics, admin, settings, **webai/projects,audits,proposals,templates,project,preview,share**).
- `src/webai.js` : KLIR WEB AI v1 — module séparé (window.WebAI), extractible en SaaS. Discovery sécurisée (timeout 12s, pas de JS externe, anti-SSRF), audit 10 catégories 0–100 + issues avec preuve/priorité, strategy, 13 templates secteur, 9 styles, builder par modèle (édit IA ciblée, versions, preview iframe sandbox, share avant/après, proposition 3 packages configurables, leads → CRM, statuts workflow, admin règles+packages+AI usage).
- `src/projects.js` : PROJECT WORKSPACE v1 — Prospect → Projet → dossier personnalisé (window.KlirProjects). Service Activation Engine (8 services : Website, KlirPromo, SEO, Klir IA, KlirBuild, KlirPay, KlirMarket, Klirline OS — score/priorité/raisons depuis WebIntel+Opportunity, seuils configurables), cycle PROSPECT→QUALIFIED→OPPORTUNITY→PROJECT→CLIENT, pipeline par service avec synchronisation Klir Web AI, tâches/documents/comms/RDV/notes/propositions, prochaines actions.
- `src/team.js` : COMPTES & ACCÈS v1 — annuaire local des inscrits (email, entreprise, plan, dates + miroir kv), invitations par code (7 jours, rôle), rôles Admin/Éditeur/Lecteur + permissions granulaires modifiables, utilisation du compte d'un tiers (données routées vers son coffre, jamais de mélange), révocation immédiate. Portée locale à l'appareil : le multi-appareil réel exigera le backend (voir MIGRATION).
- Compte dans le menu : groupe MON COMPTE (👤 Mon profil + 👥 Équipe & accès), pied de sidebar avec « ⏻ Se déconnecter », barre du haut avec e-mail + « 👤 Mon profil » + « ⏻ Se déconnecter », page #/profile. - Klir Web AI : jauges de score (SVG), aperçus en direct (iframe srcdoc), stepper pipeline, nuanciers, bannières templates, toggle desktop/mobile. Fluidité : progression 1/3-2/3-3/3 sur audit/génération, position conservée après chaque action (plus de saut en haut), timeout analyse 12s→8s. Revue complète : plus aucun « undefined » affiché (fallbacks secteur), landing réparée (nav + tableau démo), français relu (adaptateur, crédits d’usage, pluriels, page client en français), aucun bouton mort sur 31 routes. - Secours & récupération (`src/recovery.js`, sans plateforme) : fichier de secours chiffré (AES-GCM + PBKDF2, mot de passe ≥ 8) avec tous les comptes et dossiers — à garder (e-mail à soi, USB) ; restauration sur tout appareil via Réglages. - Compte Klir (`src/nuage.js` + script `<script type="text/x-server-plugin">` dans index.html, import server-plugin) : compte gratuit hébergé par Perchance, ZÉRO config — inscriptions/logins multi-appareils, mots de passe jamais stockés (sel unique + SHA-256 pur JS étiré), code de récupération XXXX-XXXX-XXXX-XXXX en cas d'oubli, synchro auto (push après chaque sauvegarde, pull à l'ouverture). Contraintes runtime respectées : index JSON compact + cases fixes de 320 Ko (travail par RPC borné), envoi morcelé 48 Ko, lecture par tranches binaires 64 Ko décodées côté client, rate-limits par conn.net. Actif après Sauvegarde du générateur (avant : émulateur local vidé à chaque refresh). Hors Perchance (export statique) : regardez le fichier de secours. Audit 2026-10 : 28 routes + tiroir prospect + modales + onglets projet/webai vérifiés, aucun bouton mort trouvé.

## État (PROD V1 — klirprospect.klirline.ca)
Scores : Data Quality / Relevance / Confidence / Intent / Opportunity (cliquables → détail du calcul). Connecteur live Sirene (recherche-entreprises.api.gouv.fr, sans clé, recherches France). Déduplication multi-clés (domaine/tél/email/nom/adresse) + Exact/Possible + fusion. Radar configurable (signaux, fréquence) + stats de scan. Mode DEMO/LIVE. Funnel analytics + pipeline $. Export autonome : voir le zip du site (index.html + src/).
Menu groupé (Prospecting / Ideal Customer / CRM / Klir AI / Outreach / Analytics / Settings + Outils). Dashboard : KPIs Prospects/Qualifiés/Opportunités/Actions, top opportunités, carte ICP + CTA, Copilot inline. CRM en 5 vues (Companies/Contacts/Leads/Deals/Activities), deals créés depuis les leads (€, Won cumulé), contacts publics + ajout manuel. Copilot et Messages en pages dédiées. Parcours ICP → Recherche → Qualification → Radar → CRM → Copilot → Outreach vérifié bout en bout.
Fait : + ICP Builder (défaut recherche/Radar/lists + fit /100), Radar opportunités (nouveaux/changements/signaux → analyse → action), Smart Lists (5 presets + personnalisées), Copilot (« que faire ensuite ? » avec actions), waterfall enrichment avec provenance, lead scoring réglable, import CSV → normalisation/déduplication, monitoring (watchlist + scans), intégrations Gmail/Outlook/HubSpot/Pipedrive (à configurer), API locale + clé + console + webhooks, crédits 🪙 avec coûts et recharge.
Non-fait (backend requis) : sources réelles, multi-tenant serveur, envois réels, Stripe, tests auto — voir `src/MIGRATION.md`.
