# Klirline AI Company — architecture cible

Statut : **cible**. Ce document fige l’organisation virtuelle de Klirline Inc. Il ne lance aucun agent, aucun orchestrateur et aucun connecteur.

Cette semaine, le seul système de travail est KlirProspect. Le Control Center se construit plus tard, après les premières ventes, et seulement par étapes.

```text
Cette semaine
KlirProspect → qualification → préparation commerciale → Philippe décide

Plus tard, après les premières ventes
Control Center → directeurs IA → agents → plateformes
```

Le but n’est pas d’avoir cent agents. Philippe dirige Klirline. Les agents gèrent le travail quotidien. Chaque département a un responsable IA. Les responsables se contrôlent. Les actions sensibles remontent au CEO. Les plateformes fonctionnent comme une seule entreprise.

## Principe

Chaque agent a un poste, des compétences, une mémoire, des outils, des objectifs et des limites. Chaque groupe a un supérieur. Aucun agent important ne travaille sans supervision. Philippe Azor reste l’autorité finale.

Un agent ne clôt pas une tâche sensible par « c’est fait ». Il produit une mission, une analyse, une action proposée, puis attend la validation de son supérieur avant l’exécution.

## Autorité du CEO

Philippe Azor n’est pas remplaçable par un agent. Il contrôle :

- la stratégie ;
- les gros contrats ;
- les gros paiements ;
- les partenariats ;
- les embauches ;
- les prix importants ;
- les décisions sensibles ;
- les accès critiques ;
- le lancement de nouvelles initiatives.

Le tableau de bord futur n’affiche que cinq files : **À approuver**, **À surveiller**, **Urgent**, **Opportunités**, **Résultats**. Le CEO ne gère pas les tâches ordinaires.

Le Chief of Staff supervise le Sales Director, le Marketing Director, le COO, le Customer Director et le Finance Director. Il reçoit leurs rapports et les présente au CEO sous cette forme : ce qui s’est passé, ce qui doit être fait, ce qu’il recommande, et ce qui doit être approuvé.

Le Security Director est indépendant des autres départements. Il surveille tous les agents.

Les Product Managers relèvent du COO. Chaque plateforme a le sien : KlirProspect, KlirLead, Klirline OS, KlirBuild, KlirPay, KlirMarket, KlirSecure, Centia.

## Postes cibles

Ces postes décrivent l’organisation future. Ils n’existent pas encore comme logiciels.

### Direction

| Poste | Mission |
|---|---|
| CEO | Philippe Azor. Autorité finale. |
| Chief of Staff | Priorise, rapporte, détecte les risques, escalade, prépare les décisions. Ne remplace pas le CEO. |

Compétences du Chief of Staff : executive management, priorisation, task management, strategic planning, decision analysis, reporting, analyse de KPI, orchestration cross-plateforme, préparation de réunions, détection de risques, escalation, workflow management.

### Ventes

Le Sales Director transforme les prospects en clients. Il est le supérieur de tous les agents commerciaux.

Compétences : vente B2B, CRM, qualification, prospection, cold email, cold calling, discovery calls, scripts, objections, négociation, propositions, closing, pipeline, forecasting, analytics.

| Agent | Rôle |
|---|---|
| Prospecting | Travaille avec KlirProspect : trouver les entreprises, enrichir, détecter les décideurs, dédoublonner, classer, scorer, recommander. |
| Outreach | Prépare et, plus tard, mène l’email (premier contact, relance, réponse, personnalisation, suivi) et le téléphone (préparation, appel via le système connecté, qualification, résumé, prochaine action). |
| Appointment | Calendrier, rendez-vous, démos, confirmations, rappels, reports, no-shows. |
| Proposal | Prépare devis, propositions, offres, packages, contrats et résumé commercial. Aucun engagement important sans validation supérieure. |

Les appels automatisés respectent les règles applicables de télémarketing, de consentement et d’identification. Tant que ces règles ne sont pas écrites et validées par un supérieur, aucun contact réel n’est automatisé.

### Marketing

Le Marketing Director est le supérieur de tous les agents marketing.

Compétences : stratégie, branding, SEO, content, social, email, paid, copywriting, étude de marché et de concurrents, campagnes, analytics, conversion, tests A/B, funnel.

| Agent | Rôle |
|---|---|
| Content | LinkedIn, Facebook, Instagram, articles, newsletters, scripts vidéo, campagnes. |
| SEO | Mots-clés, pages, contenu, backlinks, SEO technique, analyse concurrentielle. |
| Advertising | Campagnes Meta, Google, LinkedIn et autres plateformes. Budget et lancement important : validation supérieure. |

### Opérations et produits

Le COO surveille KlirProspect, KlirLead, Klirline OS, KlirBuild, KlirMarket, KlirPay, KlirSecure et Centia.

Compétences : operations management, SaaS, optimisation de processus, incidents, automatisation, KPI, SLA, qualité, product operations, intégrations.

| Product Manager | Périmètre |
|---|---|
| KlirProspect | CRM, prospects, contacts, pipeline, scoring, relances, données commerciales. |
| KlirLead | Génération de leads, campagnes, qualification, acquisition. |
| Klirline OS | CRM, ERP, automatisation, IA, utilisateurs, modules. |
| KlirBuild | Construction, projets, clients, estimation, suivi de chantier, opérations. |
| KlirPay | Paiements, transactions, facturation, risques, rapprochement, partenaires. |
| KlirMarket | Vendeurs, produits, acheteurs, commandes, marketplace. |
| KlirSecure | Audits, vulnérabilités, sécurité, rapports, risques. |
| Centia | Services et opérations propres à Centia. |

### Clients

Le Customer Success Director est le supérieur des agents clients.

Compétences : service client, onboarding, succès client, rétention, prédiction de churn, réclamations, connaissance produit, communication, gestion de comptes.

| Agent | Rôle |
|---|---|
| Onboarding | Accompagne le nouveau client. |
| Support | Répond aux problèmes. |
| Account Manager | Suit les comptes importants. |
| Retention | Détecte les clients à risque. |

### Finance

Le Finance Director et ses agents analysent, préparent et recommandent. Ils n’exécutent pas une opération financière sensible. L’exécution suit : CEO ou personne autorisée, validation, puis exécution.

Compétences : comptabilité, bookkeeping, analyse financière, budget, trésorerie, revenu, comptes clients, comptes fournisseurs, prévisions, préparation de documents fiscaux, détection de fraude.

Agents : Accounting, Billing, Collections, Financial Analyst, Cash Flow.

### Sécurité

Le Security Director surveille tous les agents, avec une indépendance réelle vis-à-vis des départements qu’il contrôle.

Compétences : cybersécurité, IAM, contrôle d’accès, vulnérabilités, réponse à incident, fraude, audit, conformité, protection des données, supervision de sécurité.

```text

   ↓
```

Le rapport remonte au directeur du département, puis au Chief of Staff, puis au CEO lorsque la matrice l’exige.

## Contrat de chaque agent

Quand un poste sera construit, il ne sera pas un simple prompt. Chaque agent aura :

- rôle et mission ;
- compétences ;
- connaissance et SOP ;
- outils et permissions ;
- mémoire ;
- KPI ;
- règles d’escalade et d’approbation ;
- style de communication ;
- traitement des erreurs ;
- journal d’audit.

## Ordre de construction

On ne construit pas cinquante agents d’un coup. Après les premières ventes, l’ordre est :

1. Chief of Staff.
2. Chaîne revenus : Sales Director, Prospecting, Outreach, Proposal.
3. Marketing Director, Content, Advertising et analytics.
4. COO et Product Managers des huit plateformes.
5. Customer Success Director.
6. Finance Director, Security Director, Analytics.

Le MVP de départ, le jour où le développement commencera, se limite à cette chaîne. Appointment, SEO, les agents clients détaillés et les agents finance détaillés viennent ensuite, sous leur directeur.

## Cette semaine : ventes

KlirProspect fait aujourd’hui le travail du futur Prospecting Agent, sous contrôle humain : trouver les entreprises, enrichir, dédoublonner, classer, scorer, recommander.

La suite commerciale — message, appel, rendez-vous, offre — se prépare pour décision de Philippe. Rien n’est envoyé, appelé, signé, payé ou publié automatiquement.

Chemin commercial actuel :

```text
KlirProspect → Sales → Leads → Clients → Klirline OS / KlirBuild / KlirPay / etc.
```
